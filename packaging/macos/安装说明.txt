OpenNova 0.1.0 · macOS 内部测试版

适用设备：Apple Silicon（M 系列），macOS 15 或更高版本。
本包未提供 Intel 版本。基础运行环境已内置，无需安装 Homebrew、Node、Python、uv 或 Xcode。
需要联网、可用的模型账号。浏览器协作需要 Google Chrome。

安装
1. 打开 DMG，将 OpenNova 拖入 Applications（应用程序）。
2. 等待复制完成，推出磁盘映像，再从“应用程序”打开 OpenNova。
3. 本包只有本地签名，没有 Apple 开发者签名和公证。如果 macOS 阻止打开，在确认包来源后，打开“系统设置 → 隐私与安全性”，按系统提示选择“仍要打开”。无需关闭系统的全局安全保护。

首次使用
1. 如果网络需要代理，先在控制面板填写你自己的 HTTP/HTTPS 代理地址并保存。
2. 点击“登录 ChatGPT”，在浏览器官方页面完成授权。本包不含任何人的账号或密钥。
3. 点击“启动服务”，再点击“打开 OpenNova 对话”。
4. 如需浏览器协作，点击“连接浏览器扩展”。在 Chrome 的 chrome://extensions 打开开发者模式，选择“加载已解压的扩展程序”。目录选择框中按 Command+Shift+G，粘贴控制面板显示的扩展目录。
   默认安装位置：/Applications/OpenNova.app/Contents/Resources/app/extensions/browser
   打开扩展的设置页，填入控制面板给出的服务地址和配对码。配对码有效期 60 秒，过期后重新点击“连接浏览器扩展”。
5. 需要持续语音时，在控制面板保存自己的豆包 ASR API Key；TTS Key 可单独填写，或使用已开通 TTS 权限的同一密钥。到对话窗口点击“开启语音”，按 macOS 提示允许麦克风访问。未配置语音仍可使用文字。
6. 引用其他应用的当前文档时，可能需要在 macOS“隐私与安全性 → 辅助功能”中允许 OpenNova。权限由你在目标 Mac 上授予。

数据和退出
配置、账号存储、会话、任务、默认工作目录和日志均位于：
  ~/Library/Application Support/OpenNova/
控制面板提供“打开数据目录”和日志入口。默认工作目录为该目录下的 Workspace。
应用默认使用 19560 / 19561 两个本地端口，与开发版默认端口分开。
关闭控制面板窗口后服务继续保留；使用菜单“退出 OpenNova”停止本次启动的服务。
更新时先退出应用，再替换应用程序中的 OpenNova.app。保留用户数据目录即可保留记录。
删除应用本身不会删除用户数据。卸载数据前请自行备份需要保留的内容。

可选能力
图片/视频云端生成：将自己的方舟 API Key 保存为用户数据目录下 config/ark.key，限制为本人可读；未配置不影响文字与文档工具。
联网搜索：在 config/secrets.local.json 的 web.deepseek_api_key 中填写本人密钥，并在 config/voice.local.json 启用 web.enabled、将 web.provider 设为 deepseek，重启服务后生效。
Studio TTS、Spark 视频服务和其他远端工作节点需要另外配置。此内部版控制面板默认使用豆包云端语音。
安装包不含旧机器的项目素材、聊天记录、Chrome 登录资料和云服务凭据；需要的项目文件请另外复制并在新机重新选择路径。
执行任意开发项目仍可能需要该项目自己的编译器和依赖，这些不属于 OpenNova 的基础运行环境。

故障排查
点击“打开日志”查看 application.log 与 voice/launcher 下的日志。不要公开含个人内容的完整日志。
如果提示端口被占用，先检查是否已有该应用运行；本应用不会强制终止其他程序。
更改代理后停止服务再启动；更改语音密钥后关闭语音再开启。
如遇系统权限提示，以目标 Mac 的设置为准。

本内部测试包只用于个人试用。Apple Silicon 的真实跨机登录、麦克风、扬声器和系统权限需要在目标设备上完成验收。
