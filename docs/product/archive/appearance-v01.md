# openNova 上一轮外观研究

归档时间：2026 年 10 月 4 日。以下保留原桌面终端提案，作为设计过程记录；当前并列候选方案见[产品概念文档](../opennova-product-concept.md)。

## 产品外观设计

### 形态路线比较

以下是本稿提出的三个方向。**建议先深化桌面终端，并用现有随身设备验证接续体验。** 这一选择源于已认可的桌面协作场景，并不意味着已经完成硬件选型。

| 方向 | 希望带来的体验 | 必须解决的问题 | 本稿安排 |
| --- | --- | --- | --- |
| 桌面终端优先 | 工作时有稳定的位置、可见状态和物理控制 | 桌面占用与独立硬件价值，能否融入电脑工作流程 | 主方案，先画清楚并验证 |
| 眼镜优先 | 助手在移动中共享部分视野，随时提供提示 | 佩戴接受度、续航、视觉权限和显示负担 | 备选，先明确必须依赖第一视角的任务 |
| 便携终端优先 | 拿起即可交流，放下后形成桌面入口 | 相对手机的额外价值、携带与充电负担 | 备选，先验证专用实体入口的必要性 |

### 主方案的整体造型

![openNova 桌面终端外观概念图](../assets/opennova-desktop-concept-v01.png)

外观意向图：黑色玻璃视窗、银色金属外壳、低矮底座与屏幕内光形。由内置 ImageGen 生成，供讨论比例与材料气质；图中结构与效果未经工程验证。[查看生成提示词](../assets/opennova-desktop-concept-v01-prompt.md)

建议采用一块微微后倾的直立黑色视窗，配以连续的金属背壳和低矮椭圆底座。整体轮廓柔和、完整，侧面保留适当厚度与重心感，放在显示器侧边也能成为有识别度的物件。

正面画面与深色玻璃相融：安静时只保留克制的状态标记，交流时出现光形或人物，工作时显示当前议题与待决定事项。设计重点是“有自己的位置、知道何时回应”的存在感。

**概念体量目标：约高 165 × 宽 105 × 深 75 毫米。** 深度包含底座。数值只用于评估桌面比例，需根据显示、声学、散热和结构验证调整，不是工程规格。

### 材料与细节

| 部位 | 设计提案 | 对应的使用目的 |
| --- | --- | --- |
| 正面 | 深色玻璃与黑色显示区域尽量融为整体，适度控制反光 | 画面出现时集中注意力，安静时保持整洁 |
| 背壳与侧面 | 细腻哑光银色铝合金，连续圆角 | 建立稳定的轮廓与触感，适应工作与居家环境 |
| 底座 | 低矮椭圆体、隐藏式防滑脚垫，后侧集中走线 | 稳定放置，保持桌面整洁 |
| 状态提示 | 底座前方短光缝，配合屏幕文字或图标 | 从侧面也能察觉状态，避免只靠颜色辨认 |
| 物理控制 | 顶部具有明确档位的静音滑块，关闭状态可直接辨认 | 无需进入菜单即可暂停拾音；硬件断路作为后续工程要求 |
| 声学开孔 | 融入侧面或底座的细密孔区 | 支持语音交流，具体布局由声学测试确定 |
| 可选视觉入口 | 若保留摄像头，设置可见的机械遮挡与启用指示 | 用户明确知道何时允许采集环境；是否纳入首版待定 |

建议先使用一种主配色完成设计收敛：银色金属、深黑玻璃、低饱和的冷白光。暖色只用于明确的状态提醒。材料名称与表面效果属于设计意向，需要样件确认触感、反射和耐用性。

### 画面与动态设计

默认呈现可采用简单、可辨认的抽象光形，以变化节奏表达倾听和回应；工作时让位给当前任务。原创人物形象是待确认的探索分支，其外观、出现时机和实际价值另行讨论。

| 状态 | 建议呈现 |
| --- | --- |
| 安静可用 | 低亮度标记或熄屏，由用户选择 |
| 正在倾听 | 短光缝与明确的拾音标记；讲话结束后及时退出 |
| 正在执行 | 简短动作说明与进度，例如“正在整理资料” |
| 等待决定 | 一个清楚的问题；用户可以稍后处理 |
| 已完成 | 展示结果入口，短暂反馈后回到安静状态 |
| 静音或连接中断 | 持续可辨的图标和文字；不以循环动画假装工作仍在推进 |

静态外观图仅表达造型、材料和屏幕呈现方向；状态变化、静音电路、光学效果及交互能力都需要后续验证。

### 全息与空间呈现的边界

主方案的概念图采用普通实体屏幕。黑色背景、光形层次和动画可以探索视觉纵深，但画面始终位于屏幕内。

未来可另行比较桌面立体显示和需要佩戴设备的 AR 空间角色。Microsoft 对 HoloLens 的说明展示了通过近眼显示将虚拟对象固定在空间或随人移动的方式；这是一条需要佩戴设备的呈现路径，相关文档仅用于理解原理，不作为采购建议。[Microsoft 显示与空间交互说明](https://learn.microsoft.com/en-us/windows/mixed-reality/discover/hologram)

Joi 的电影形象仍作为存在感参考。Framestore 介绍了透明外壳与故障表现等视觉效果，它们说明电影如何塑造角色，不证明同样效果已能由小型消费设备实现。[Framestore 制作说明](https://www.framestore.com/work/blade-runner-2049)
