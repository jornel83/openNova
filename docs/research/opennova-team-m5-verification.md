# OpenNova 团队 M5：技能复用与经验沉淀

M5 将已有 `video-production`、DeepSeek Bot 的员工能力绑定和 Harness 的技能加载接入 OpenNova。主对话、独立员工任务、成果验收和经验提炼使用同一套技能目录与版本标识；任务、会话、记忆、候选和版本归档继续保存在仓库外。

## 现有能力的复用方式

- Harness 提供 `skills` 注册服务、系统提示中的可用技能和 `skill` 工具。OpenNova 注册技能目录，并为每个员工执行轮提供固定的技能资源归档，不启用任意用户目录的全局技能扫描。
- DeepSeek Bot 的 `capabilities` 保存员工绑定。OpenNova 的 SQLite 保存版本、候选、使用记录和同步意图，不另外建立员工身份。Bot 的本地扩展保留技能资源目录、版本、启用状态和调用策略；补丁记录在 `patches/bot/0001-skill-bundles.patch` 与 `upstream.lock.json`。
- OpenNova 负责 Task/Run、独立工作目录、工具权限、视频等待、成果与验收，以及候选转正式技能。技能不会改变任务权限、预算、验收要求或用户授权范围。

## 技能与任务

首次初始化向总管绑定内置技能。员工在“管理员工 → 技能配置”选择技能；普通新任务默认提供员工已绑定且启用的技能，由模型判断何时加载，也可明确指定或本次不使用。只读员工可读取其固定技能资源，仍不能写文件或执行命令；Full Access 沿用已实现的当前系统用户目录权限。

当前执行及同一员工接续原任务沿用原技能归档。更新、回退、停用作用于后续新任务，不改写历史 Run；交接到另一员工按新员工绑定重新选择。保存新技能默认绑定总管，保存经验候选还绑定来源员工。绑定与 Bot 镜像存在独立持久同步记录，失败会显示并重试；用户后续取消绑定后，重启或重放旧请求不会自动加回。

前台提供 `skill_list`、`skill`、`skill_extract`、`skill_manage`。语音转写和文本使用原对话入口。HTTP 对应 `/skills`、`/skill-action`、`/skill-history`、`/skill-candidate`，沿用原连接授权。变更绑定 revision 与稳定 actionId；来源变化或陈旧页面操作会拒绝。

## 从成果提炼经验

默认开启“验收通过后自动整理经验候选”，默认关闭“自动启用”。新员工 Agent 成果通过当前验收后，创建独立只读提炼任务：读取固定报告、上下文与必要文本成果，调用 `skill_draft` 提交具体、参数化的方法。此内部任务不计入用户团队工作总数，也不会重做原业务。

完成草稿后可检查、改名和编辑，再保存为正式技能。再次执行时必须处理新的输入并重新验证，旧验收不能充当新结果证据。自动启用仅在用户明确配置后生效，且不覆盖已存在的同名技能。同名候选保留待保存状态，更新已有技能需当前 revision。

历史已验收任务不会在升级或重启时自动补跑提炼；可在成果卡或原对话明确要求整理。提炼失败可显式重试，新请求只重试提炼，不重做原工作。来源发生修改、返工、交接、关闭或验收失效，旧候选不能启用，尚在执行的内部提炼会清理停止。技能使用与验收反馈独立记录，不因关闭自动候选而丢失。

自动整理要求参数化输入输出、去除私人事实和凭据；常见个人路径与密钥字面量另有校验。这不是对任意私人内容的完美识别，默认保留人工查看和启用步骤。技能不自动发布到开源仓库。

## 视频工具与等待

正式接入 `video_validate`、`video_submit`、`video_status`、`video_wait`、`video_download`、`video_edit`。工具仅在完整执行且已选择 `video-production` 的员工任务可用。正式参数校验、Python 工具代码、引用资源随 Run 一并固定；升级源码不会让旧轮偷偷换脚本。

提交、远端编号、输出目录、查询和下载回执均持久化。`video_wait` 将任务转为等待事件并释放执行槽；轮询继续查询同一个远端任务，成功、失败或等待期限到达后幂等接续原任务。远端提交结果不明时保留待核对状态，不能因为超时直接重复收费提交。重启恢复跟进，暂停/关闭后不会被旧回调重新启动。停止本地跟进不代表远端取消。

视频服务凭据保存在仓库外，默认读取 `~/.config/opennova/ark.key`；也可设置 `OPENNOVA_ARK_KEY_FILE` 指向其他外部文件。不要将凭据写入技能、候选或源码。统一启动也支持进程环境中的 `ARK_API_KEY`，仅透传这个明确支持的视频凭据名，其余通用秘密变量仍按原启动策略过滤；推荐使用外部文件以便重启复用。模型不接收密钥值。未配置凭据时可以进行参数校验和已有素材的本地剪辑；真实生成需要服务账号和可用额度。

交付文件按当前 Run 收集，远端成功、下载成功和验收通过分别展示。当前 Run 的可信视频下载/剪辑回执允许单文件 512 MiB、媒体合计 1 GiB 的独立成果快照；普通文件仍为单文件 20 MiB、合计 64 MiB。快照采用独立复制与分块哈希，核对原件和副本，超限明确显示未完整保存；不会把只有原文件引用的记录说成已保存快照。非文本视频不能由当前只读文本验收器确认画质，应由用户打开播放并验收；本地探针与命令退出码只能支持文件/格式检查。
