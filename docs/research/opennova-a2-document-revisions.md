# A2 第三批：继续修订 Nova 的 Word 和 PDF

2026-11-19 更新。以下记录保留 A2 当时直接另存新版的验收结果。当前前台修改 Word 或 PDF 先生成待确认的对照，详见 [A4 计划](../superpowers/plans/2026-11-19-a4-change-review.md)。

2026-11-18。前台工作项目内可以按成品路径，或说“修改当前文档”，继续修改 Nova 生成的同格式 Word/PDF。成功回执包含新版和保留的旧版位置。原稿 `计划.docx`、第二版 `计划.v2.docx`、第三版 `计划.v3.docx` 各自独立可打开。新建、修订和只读检查使用同一个 `document_generate` 工具；后台新建研究报告与重启接续的后续交付见[第四批记录](opennova-a2-background-research.md)。

- **沿用什么：** 从本项目、该版本保存的生成底稿开始，支持修改标题、正文块、版式、单个表格单元格、汇总单元格和研究结论。没有要求修改的内容与引用沿用原版本，修订结论的新引用重新核验。历史文件缺少可可靠恢复的底稿时，停止修订。
- **如何防止覆盖：** 开始及发布前均检查基准文件的身份、版本和内容哈希；目标文件只允许原子新建。磁盘文件被手动编辑、删除或替换，便停止。引用旧版且已有后继版本时，告知最新版本的位置，不擅自改用新版；目标路径已有其他文件时也不覆盖。对受管路径，普通文本写入、编辑工具不能替代文档修订工具。
- **不会自动做什么：** 不合并外部编辑，不用旧底稿重建或覆盖用户手里的文件，不自动打开成品。查看内容、分版保存成功、内容核验通过与逐页视觉验收是不同的状态。这里不提供任意第三方 Word/PDF 的保真编辑。

**真实对话验收。** 使用临时项目和正式生成器预置一份 Word 和一份 PDF。两次真实模型对话分别定位指定段落并另存第二版，独立从 Word XML 及 PDF 文字层确认指定段替换为 “Confirmed quantity: 5122.”、未点名的段落完整，两个原文件与其快照的哈希均未变。然后用独立程序修改第二版 Word 的实际正文，生成仍可正常读取的 DOCX；第三次对话请求改标题，得到 `document_revision_source_changed`，没有生成第三版，手改文件哈希保持不变。验收未重启用户 Bot。

**定向回归。** 58 项通过，涵盖真实 Harness 的修订、重启后当前文件、二进制和底稿核对、手改竞态、项目隔离、普通写入保护、引用继承、长表格与回执显示。多页长表用例将第 60 行从 60 改为 75、合计从 1830 改为 1845；独立读回新版 PDF、核对旧版哈希，并验证旧值不符时整次不发布。
