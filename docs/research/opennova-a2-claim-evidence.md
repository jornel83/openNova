# A2 第二批：从研究结论回查原文

2026-11-18。适用范围：OpenNova 前台工作项目。可以说：“把验收报告第 2 页的关键结论保存成研究笔记，每条附上原话。”之后可以问：“这条结论引用的是哪一版？原文怎么说？”

笔记按条区分资料事实、分析推断、用户决定和待核实问题。一条结论可有多份证据，也可以明确没有出处。宿主从本项目已完成的读取回执取得文件身份和 SHA-256，重算私有快照的哈希，再核对指定位置。不会把模型先前的回答当作原文，也不使用其他项目的回执。核实的是**某段原文确实出现在该版本和位置**，不是判断原文是否真实或推断是否成立。

| 来源 | 笔记里的可核对位置 | 未自动确认的情况 |
| --- | --- | --- |
| PDF | 原文件物理页，从 1 开始、含封面；指定页段的读取回执只能引用该范围内的原页。保存文字层的实际摘录。 | 扫描无文字层、加密、错页、改写或原文不存在。页内相同文本不区分第几次出现。 |
| Word | 正文顶层非空段落，从 1 开始；按实际段内文字核对。 | 不推断分页，不计表格、文本框与页眉页脚；不可靠的域或修订降级。 |
| Excel | 工作表名和单元格，如 `Counts!B3`；核对静态文本或受支持的普通数值。 | 不把公式缓存、合并区域里猜测的值或不支持的显示格式当作已核实原文。 |
| 网页 | 当次保存的正文观察编号、URL、观察时间及观察文本哈希；仅在这次实际保留的文字中匹配。 | 只有搜索摘要、只有链接，或正文未保留该引文。相同 URL 的不同观察不混用。 |

宿主不匹配的候选摘录不会进入已核实引文栏；正文可以明确提出假设或保留待核实问题。原读取只覆盖部分内容时，笔记保留该限制。新引用依赖可用快照；已保存笔记按当时的结论与核验记录回查，不随原件的变更、删除或项目资料列表变化而替换。这不是对当前磁盘文件的重新认证。

带出处的 Markdown 笔记通过前台 `research_note(save)` 使用 Harness 的文本写入能力新建；Word/PDF 通过既有 `document_generate` 的可选 `spec.claims` 输出。都不覆盖已有成品。用 `research_note(lookup)` 按当前项目的成品路径、笔记编号或文档成果编号回查；没有标识时列出近期笔记。普通 Word/PDF 的 `sources.locator` 自由文字不产生“引文已核实”标记。非研究笔记、旧生成成果不会被自动重写或补造出处。

**验证。** 78 项定向测试覆盖读取、证据解析、笔记保存/回查、实际 Word/PDF 文本读回、跨项目拒绝、原件和快照变更、取消及重启。另在隔离 Bot 中运行真实模型：生成数量随机的两页 PDF，指定只读第 2 页，保存研究笔记；停止 Bot、删除源 PDF、重启后，追问旧依据。出站工具记录依次为 `document_read → research_note(save) → research_note(lookup)`，最后一步没有重读 PDF。实际回查到 `sample.pdf`、第 2 页、完整版本哈希和原句 “Accepted units: 6702.”。没有使用用户资料或重启用户 Bot。

可复跑的隔离验收脚本：[verify-note-evidence.mjs](../../scripts/verify-note-evidence.mjs)（Node 24、已有模型授权）。本机本次记录：`output/verification/a2-note-evidence/5d17089b-4c00-4413-a797-eb73181e9232/`；定向回归日志在同一上级目录的 `targeted.log`。Word/PDF 导出和 Office/网页位置核对有独立样本及离线回归；没有把这些结果算成各格式的线上模型验收。
