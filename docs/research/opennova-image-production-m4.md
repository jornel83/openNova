# M4 验收：图片与动图技能

2026-11-18。OpenNova 前台内置了 `image-production`。它区分提示词、静态生成或改稿、确认稿转 GIF、本地导出和抽帧审阅。项目工作对话和语音入口继续使用同一套请求绑定。本阶段没有接入员工或后台生成任务。

- **角色**：在言昕项目的 `.opennova/image-characters.json` 配置了言昕、小艺、伍宝的确认版本和参考图 SHA-256。使用角色时仅查询当前项目；参考图被改动时，在生成前拒绝使用旧版本。样式和动作按本次作品配置。
- **升级**：新技能出现在已有安装的主助手技能列表中，不改变员工绑定或恢复用户已经停用或移除的技能。回归用旧安装状态、原有员工技能和主动移除后的重启验证。
- **工具冻结**：技能、执行器、schema、所需模块和依赖清单都随版本归档。验证归档内容后运行；当前版本升级不改变已经提交的操作。运行环境由 `pnpm run setup -- --image-only` 按依赖清单隔离安装。
- **视觉检查**：成果卡可以播放和打开 GIF。「抽帧审阅」只把确定版本的 PNG 检查页交给视觉模型，记录源 GIF 哈希、模型、总帧数和实际确认的编号；不会切换当前文件，抽帧结论不代表检查所有帧。
- **无需生成的动作**：真实对话“先给提示词”完成，查询到伍宝的确认版本，没有 `image_generate` 或 `gif_generate` 操作。离线通过真实 Harness 验证本地导出首帧无远端生成、项目切换后角色不可串用。
