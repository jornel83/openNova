# 后台摘要接续与错误诊断

更新：2026-10-25。适用于当前桌面 Demo，启动命令及设备/TTS 参数不变。

## 1. 后台摘要接续

原生 Bot 的 `writeNote`、`writeCheckpoint` 请求使用 `purpose=compaction`，但没有 `ownRequest` 的 WeakMap 标记。OpenNova 原来的入口要求有前台请求或该标记，导致空闲时生成摘要被 `bridge_request_required` 拒绝。反复退避后，长会话可能等到上下文接近上限才换段。

现在允许当前 Bot 及其已有分段的 compaction 请求，继续使用 Bot 原生摘要、检查点和换段。摘要请求保留历史工具结果，但不提供新的可执行工具；返回工具调用也不会被执行。摘要不会成为聊天回复或 TTS 播报内容。已有取消与换段等待机制保留，不重放已执行的工具。

日志 `Bot context maintenance` 记录会话、阶段、运行/完成/失败/取消和耗时。一次模型调用完成表示摘要内容生成成功；摘要格式检查、实际换段和上下文续接仍由原生 Bot 完成，不能只看这条日志就判定换段成功。

## 2. 错误诊断

之前三处丢失信息：普通 Error 在 Harness 模型管线中被归为 UNKNOWN；轮次结束只提取错误字符串；Bot 请求结果再次只保留字符串。

目前链路为：

```text
SIWC 错误 → 清洗后的原生 LlmError → Harness finish / turn/end
         → Bot 持久诊断 → 网页 / 文字终端 / 语音终端
```

保留允许的错误码、阶段、HTTP 状态及格式有效的服务请求编号。OpenNova 请求自身的编号仍在请求记录里。后端 `Bot turn failure` 日志还包含会话和本轮耗时，用于关联调查。

| 情况 | 处理 |
| --- | --- |
| 网络连接失败 | 保留 `network_error` / `connection_error`，提示检查网络与代理 |
| 回复途中断流 | 保留 `stream_interrupted`，不发布部分回复 |
| HTTP 401 / 403 | 显示实际状态，区分凭据与访问拒绝；403 不直接认定为 VPN 问题 |
| HTTP 429 / 5xx | 提示请求受限或上游服务异常，保留服务请求编号供排查 |
| 明确的未知模型错误 | `agent_runtime_failed`，保留有效状态和编号，不伪装成正常回复 |
| 未取得完整轮次 | `incomplete_agent_turn`，提示查看已执行的操作记录 |
| 用户取消 | 显示已停止，清除取消过程中附带的模型失败诊断 |

不保存任意 SDK 错误正文、原始响应、凭据或 prompt。对历史记录不会补造已经丢失的状态；新发生的错误才有完整诊断。修复诊断不等于修复实际代理或服务故障，也不新增失败工具的自动重试。模型 HTTP 503 的自动恢复见下文。

## 4. 模型 HTTP 503 自动恢复（2026-10-25）

已接入 DSH 原生 `llm-retry`，由 OpenNova 的模型适配器提供范围明确的策略：只在模型请求收到 HTTP 503 时重试当前失败步骤，最多额外尝试两次，分别等待 1 秒、2 秒。已有整轮超时继续生效；成功的搜索、网页读取、文件或 Shell 操作不会因为请求重试而再次执行。没有重新提交用户消息。

网页、环形 Nova 状态及文字/语音终端显示“模型暂时繁忙，正在自动重试（1/2）”。提示本身不会作为回答送入 TTS。恢复后继续原回复；用户停止、插话或关闭服务会取消等待；两次重试仍失败时保留最终错误诊断。

`Bot model retry` 日志和请求的 `modelRetry` 字段保存重试编号、步骤、次数、等待时间、状态与清洗后的诊断。失败分类为 `model_service_unavailable`，保留 HTTP 503。`/health` 的 `modelRetry` 展示策略；原始服务错误正文不进入日志。

其他 HTTP 状态、网络错误、断流、不完整回复及失败工具不扩大重试范围。后台摘要继续由原生 Bot 的独立机制管理。自动重试减少偶发故障带来的重问，不能保证持续故障一定恢复。

验证采用受控 SDK 故障注入，经过真实 DSH 模型适配器与 agent loop：工具成功后503再恢复，工具只执行一次且结果保留；持续503恰好共3次模型请求；等待期间取消不再调用模型；401/403/429/500/502/504、网络及断流不重试。进度持久化与客户端展示也有回归覆盖。不修改真实VPN制造故障。

本次完整回归：Node 362/362、语音 Python 105/105、网页构建通过，独立审查通过。日常 Bot 已在空闲时重启，身份和当前会话保留；启动命令不变，刷新网页加载新提示。验证记录：`output/bot/model-503-retry-verification/`。
