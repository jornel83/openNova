# OpenNova 通用员工执行能力与验收

2026-11-07。员工职责、执行权限与任务模板已分开。新任务默认通用工作和完整执行，后台员工可以组合文件、脚本、联网和浏览器工具完成工作。总管自动验收与返工仍属于团队 M2。

## 使用方式

右侧“任务 → 员工团队”添加或编辑员工；擅长方向可不选，仅帮助分工，不限制员工承接场景。“新建 Agent 工作任务”提供以下配置。

| 配置 | 作用 |
| --- | --- |
| 执行权限：完整执行（Full Access） | 按任务要求读写当前系统用户有权访问的任意目录，命令也可使用外部工作目录；使用已接入的联网、浏览器和本地文档工具 |
| 执行权限：只读 | 读取任务目录内资料、联网搜索和网页抓取；不提供写文件、命令及桌面交互工具 |
| 通用工作模板 | 默认创建普通独立目录，不依赖 Git；可选复制项目内文件，每个最多 20 MiB、最多 20 个 |
| 代码工程模板 | 准备独立 Git 工作目录；支持差异查看及显式应用到原工程 |
| 文本资料模板 | 复制明确指定的文本输入，每个最多 64 KiB、最多 10 个；完整执行时同样可运行处理脚本 |

通用与资料模板默认使用输入副本，在独立目录保存并展示成果。Full Access 可按用户明确要求修改原文件或交付到其他目录；“不修改原工程”“只排查”等任务约束仍然生效。页面中的工作区文件差异只覆盖独立目录，外部修改直接作用于实际文件。未完成工作区准备时不展示原目录文件为成果。自动检查接续仍需明确启用，有次数和期限限制。

可以对总管说：“安排资料员后台读取 README.md，生成一个处理脚本，运行后输出项目介绍报告；使用通用工作模板，完成后保留报告文件。”如需输入副本，可在 inputFiles 中明确传入 README.md；Full Access 也可通过原工程绝对路径直接读取。主对话提交后返回，任务面板显示负责人、实际工具步骤、退出码和成果。

## 实现

- `tasks/execution.mjs` 统一 `permission=full|read-only`；新任务记录 `policyVersion=2`，旧 `mode` 参数作为兼容映射，冲突参数拒绝。任务模板不裁剪新任务的工具列表。
- `team/registry.mjs` 继续复用 DeepSeek Bot 身份、职责和记忆。历史 `taskTypes` 保留为擅长方向，移除按场景限制派工；启用状态与当前执行身份仍校验。
- `tasks/agent-runner.mjs` 运行独立持久工作会话。文件与命令由原工具执行，资料和通用工作区仍在外部任务目录内。
- `tasks/task-research.mjs` 复用原生搜索、抓取与来源记录。来源数据库位于各任务 `agentHome/research/bridge.sqlite`，同任务跨轮回查；失败或取消也保留已经取得的来源，HTTP 错误步骤标为失败。搜索凭据通过子进程环境传递，不写入运行补丁。
- `tasks/bridge.mjs` 给每个 Run 签发独立凭据，只能调用该 Run 的准入、检查与宿主工具接口；不能调用关闭宿主、管理团队等接口。每次核对任务、Run、分配版本、启用状态和权限，暂停、取消和连接断开会中止调用。
- `tasks/host-tools.mjs` 复用现有浏览器与文档工具。桌面操作串行且前台优先；任务保有自己的页面引用、操作记录与回执，不借用前台页面。未知回执不盲目重放。后台可以关闭自身引用的标签页，不能关闭共享工作窗口。

## Full Access 目录语义修正（2026-11-08）

此前 `permission=full` 只放开工具列表，但文件和命令工作目录仍被 `outside_task_workspace` 限制在任务目录，导致已有完整执行权限的员工无法读取原工程 README 或仓库外日志。现统一按本机文件访问权限处理：`policyVersion>=2`、`permission=full` 的普通员工任务可使用当前系统用户有权访问的目录；相对路径仍以任务目录为默认基点，绝对路径按实际目标访问。正常符号链接按操作系统权限解析。文件读写、搜索、同步命令、异步检查和本地文档打开使用一致范围。

只读、旧契约与总管独立验收保持原有目录范围；总管验收仍只读取本轮复制的报告和证据。已有 v2 Full Access 任务无需改写权限记录，新执行轮即使用修复后的行为。任务的原始目标与约束继续保留；权限更新本身不会自动接续等待中的任务或改变系统授权。`inputFiles` 仍是模板的复制输入配置，不是 Full Access 的目录白名单。

成果默认保存到任务目录，用户明确指定其他目录时可以交付到指定位置。外部文件不会自动复制为验收证据，也不会自动加入工作区差异；任务应报告实际交付路径，必要时在任务目录保存可核验的成果副本。

## 当前范围

完整执行表示使用当前已接入的通用工具和当前系统用户的目录权限，不自动新增应用连接、账号或系统权限。用户明确的任务限制始终有效。浏览器仍共用已有工作窗口，不是每员工独立浏览器账号。工作目录用于组织输入和默认成果，不构成 Full Access 的操作系统级沙箱。授权、会话、记忆、默认任务目录与来源日志继续保存在仓库外。
