# OpenNova 通用员工执行能力与验收

2026-11-07。员工职责、执行权限与任务模板已分开。新任务默认通用工作和完整执行，后台员工可以组合文件、脚本、联网和浏览器工具完成工作。总管自动验收与返工仍属于团队 M2。

## 使用方式

右侧“任务 → 员工团队”添加或编辑员工；擅长方向可不选，仅帮助分工，不限制员工承接场景。“新建 Agent 工作任务”提供以下配置。

| 配置 | 作用 |
| --- | --- |
| 执行权限：完整执行 | 使用已接入且已授权的文件读写、命令、搜索、网页读取、浏览器及本地成果打开工具 |
| 执行权限：只读 | 允许读取、搜索和网页抓取；不提供写文件、命令及桌面交互工具 |
| 通用工作模板 | 默认创建普通独立目录，不依赖 Git；可选复制项目内文件，每个最多 20 MiB、最多 20 个 |
| 代码工程模板 | 准备独立 Git 工作目录；支持差异查看及显式应用到原工程 |
| 文本资料模板 | 复制明确指定的文本输入，每个最多 64 KiB、最多 10 个；完整执行时同样可运行处理脚本 |

通用与资料模板会展示新增文件和已修改的输入副本，保留原工程输入。未完成工作区准备时不展示原目录文件为成果。自动检查接续仍需明确启用，有次数和期限限制。

可以对总管说：“安排资料员后台读取 README.md，生成一个处理脚本，运行后输出项目介绍报告；使用通用工作模板，完成后保留报告文件。”创建时应明确传入 README.md。主对话提交后返回，任务面板显示负责人、实际工具步骤、退出码和成果。

## 实现

- `tasks/execution.mjs` 统一 `permission=full|read-only`；新任务记录 `policyVersion=2`，旧 `mode` 参数作为兼容映射，冲突参数拒绝。任务模板不裁剪新任务的工具列表。
- `team/registry.mjs` 继续复用 DeepSeek Bot 身份、职责和记忆。历史 `taskTypes` 保留为擅长方向，移除按场景限制派工；启用状态与当前执行身份仍校验。
- `tasks/agent-runner.mjs` 运行独立持久工作会话。文件与命令由原工具执行，资料和通用工作区仍在外部任务目录内。
- `tasks/task-research.mjs` 复用原生搜索、抓取与来源记录。来源数据库位于各任务 `agentHome/research/bridge.sqlite`，同任务跨轮回查；失败或取消也保留已经取得的来源，HTTP 错误步骤标为失败。搜索凭据通过子进程环境传递，不写入运行补丁。
- `tasks/bridge.mjs` 给每个 Run 签发独立凭据，只能调用该 Run 的准入、检查与宿主工具接口；不能调用关闭宿主、管理团队等接口。每次核对任务、Run、分配版本、启用状态和权限，暂停、取消和连接断开会中止调用。
- `tasks/host-tools.mjs` 复用现有浏览器与文档工具。桌面操作串行且前台优先；任务保有自己的页面引用、操作记录与回执，不借用前台页面。未知回执不盲目重放。后台可以关闭自身引用的标签页，不能关闭共享工作窗口。

## 验证

完整产品回归：498 项 Node 测试与 186 项 Python 测试通过，共 684 项。随后针对成果目录缺失补充回归，通用任务 7 项全部通过。

真实 Harness 集成覆盖以下流程；模型输出使用可重复的本地适配器，网络使用本地 HTTP fixture，扩展使用经过配对的模拟 WebSocket，不计作真人语音或真实网站验收。

1. 非 Git 项目创建通用任务，读取输入、写处理脚本、执行命令、读取交付文件；原输入保持不变。
2. 资料模板同样运行脚本，并完成显式检查失败、修复、重新检查和原会话接续。
3. 资料专长员工执行通用任务；完整执行与显式只读都由实际工具结果验证。
4. 原生抓取、来源回查、模型失败和 SIGTERM 取消后的来源保留；HTTP 503 记录为失败。
5. 后台员工通过独立 Run 凭据执行 `browser_open → browser_read → write report.md`；报告引用实际页面回执，成果可读取。
6. 只读任务不取得浏览器工具；强制越权调用不抵达扩展。伪造、跨任务、过期与已停用身份被拒绝。
7. 旧资料任务在重启接续后仍保持原工具限制，不因代码更新自动获得新增权限。

Playwright 在 460 × 900 窗口验证添加通用员工、默认模板与权限、任务提交、步骤和交付文件展示；页面宽度无溢出，控制台无错误或警告。截图位于忽略目录 `output/playwright/generic-execution/result.png`。

完整构建和 doctor 检查通过；源码审计 independent 为 true、gitlinks 为 0。原工程外部 SQLite 与 Bot 状态已备份，2 位成员、7 项历史任务及本机配置、凭据和记忆摘要核对一致。隔离测试员工与任务未加入日常数据。

## 当前范围

完整执行表示使用当前已接入的通用工具，不自动新增应用连接或账号。浏览器仍共用已有工作窗口，不是每员工独立浏览器账号。完整执行的命令拥有启动进程的本机权限；工作目录和工具策略不构成操作系统级沙箱。授权、会话、记忆、任务目录与来源日志继续保存在仓库外。
