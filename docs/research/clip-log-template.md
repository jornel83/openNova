# openNova：观影片段记录模板

先用场景名称定位，看片时再填写版本和时间码。一个记录只分析一段完整交互。影片里的可见行为和自己的产品推论分开写。

| 字段 | 记录 |
| --- | --- |
| 片段编号 | 例如 F09-C01；影片编号对应 ai-assistant-film-watchlist.md |
| 影片、年份与角色 |  |
| 形态标签 | 沿用片单标签，可多选；按本段实际出现的 AI／载体填写 |
| 电影类型 | 卡通（动画）或写实（真人实拍） |
| 片源及版本 | 平台或文件、剪辑版、语言；便于复核时间码 |
| 入点 → 出点 | 待实际观影填写 |
| 场景定位 | 事件、地点、可检索关键词 |
| 用户当时要完成什么 |  |
| AI 感知到了什么／用户说了什么 | 只记影片可见或明确交代的信息 |
| AI 做了什么，用户怎样反馈 | 提示、解释、执行、纠正、取消与结果 |
| 硬件在这里起什么作用 | 摄像头、麦克风、屏幕、移动结构、触觉或工具等 |
| 最值得借鉴的一点 | 写成具体体验，注明这是产品推论 |
| 后续需要验证的问题 | 对真实使用场景、工程条件或用户需求的疑问 |

文件名建议：F09-C01_Her_OS1-first-conversation_版本_入点-出点。示例仅表示命名格式，不是已经提取的素材。
