## 接口与行为

宿主桥接提供健康检查、固定 Bot 会话、幂等提交、状态/结果、显式取消和待确认事项。客户端退出或停止播报不会关闭宿主。会话 ID 由 Bot 当前 part 解析，不能在客户端固定旧 part。

文件工具只能读取测试目录内的普通文本文件，修改先生成差异与版本摘要；用户通过可信控制入口确认后应用。应用前检查摘要，发现冲突不覆盖，重复确认不重复写。实验目录须独占；不承诺与任意外部进程同时写入时的原子冲突保护。记忆使用 Bot 自带存储，关闭自动提取；模型的 remember/forget 先形成待确认事项，确认后才执行，更正/删除使缓存失效并抑制过时事实。历史记录和日志副本保留，本次不提供完整数据清除。

任务恢复仅验证可查询状态的受控计时任务及文件修改，重启后核对持久状态，不推断外部任务已成功。前台生成可取消；独立任务仍继续。语音使用完整最终答复作口播，完整文本保留在终端/宿主。实验阶段记录耗时，不承诺生产延迟指标。

## 验证

1. 真宿主启动、GPT 文字与工具调用；错误不生成成功回复。
2. 读取→差异→确认→应用，冲突和重复确认、目录逃逸测试。
3. 重启后同 Bot、记忆更正/删除、关闭自动记忆。
4. 客户端断线与停止播报不停止受控任务；明确取消返回真实状态。
5. 语音接线自动测试及可操作现场用例；真实模型/音频未完成的部分如实记录。

## 实施裁定

原生 Bot 浏览器组件和 API 不开放，防止其直接记忆编辑、多 Bot 与调度入口绕过实验控制。实际运行时仍由 Harness web 宿主承载，产品入口使用文字及语音桥接。
