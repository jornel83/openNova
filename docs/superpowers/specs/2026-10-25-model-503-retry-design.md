# 模型 HTTP 503 自动重试

用户已授权在 503 时自动恢复，避免重复发问。实现选择：复用已固定版本 DSH 的 llm-retry，不重提交整轮用户请求，也不另写 SDK 重试循环。

- 仅模型请求 HTTP 503 可重试；provider 映射为 model_service_unavailable，保留 HTTP 状态和有效请求编号。
- 每个失败的模型步骤最多额外重试 2 次，等待 1000 / 2000 ms，无抖动。保持既有整轮超时。
- 原生 agent loop 保留成功工具结果，重试当前失败步骤；不再次执行旧工具调用。取消、插话、服务停止可中断等待。
- DSH 原生 llm/retry、llm/retry-started 事件投影至当前 Bot 请求的 modelRetry，网页、语音终端、文字终端显示进度；通知不作为答案送入 TTS。
- 成功继续原回复；耗尽保留最终诊断。401/403/429、其他 5xx、网络错误及不完整回复不扩大重试范围。
- 后台 compaction 是独立原生机制，此次不改变它；不改 DSH 子模块、不改网络、不提交或推送现有未提交工作。

备选：重新发整轮请求会重放工具；SDK 包装会重复 DSH 的状态与取消机制，均不采用。
