# GIF 动作和验收

- 将动作拆成起势、短动作和回位，写出预计发生的秒数；表情包优先固定镜头和背景。短眨眼与闭眼蓄力不同，要明确其他时段眼睛保持张开。
- 文字必须完全固定时，使用项目内准备好的无字动作参考和同尺寸透明 PNG 文字层；`motionReferencePath` 与 `fixedOverlayPath` 成对传入，并保留原始确认稿作为 `sourcePath`。没有配套素材就说明模型生成的文字可能变化；不要把模型渲染的文字说成已逐帧校验。
- 确认 `animation.gif` 可播放、`first-frame.png` 是最终 GIF 解码首帧，`source.mp4` 是保留的生成视频。让用户看到实际尺寸、时长或帧数等与交付有关的属性。GIF 本身没有声音。
- 如果用户要求审阅，使用 `gif_review` 对成品做抽帧阅读并记录结论。关注身份、服装、表情、手部、文字和循环衔接，区分抽帧观感和全帧结构检查。只生成检查页不等于看过。
