## 不能从聊天记录推断的状态

- 历史登录与企业权限并不证明新电脑已经登录。
- 历史素材 ID 并不证明新 API Key 属于同一账号／项目。
- 有 generation_plan 不等于每张首帧都已生成。
- 有提交脚本或请求 JSON 不等于任务已经成功；看任务返回、下载文件和验证记录。
- 用户过去让某个项目静音、480p、4 秒或 15 秒，不自动覆盖新项目未定参数。
- 本次最新两张照片原文件缺失；没有实际生成当前 13.5 秒改编片。
